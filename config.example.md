# Configuración local — plantilla. Copiar a `config.local.md` (ignorado por git) y completar

Valores reales de los marcadores que usan `CLAUDE.md`, el skill y `routine/prompt.md`.

| Marcador | Ejemplo |
|---|---|
| `<EJECUTIVA>` | Nombre Apellido |
| `<EMAIL_EJECUTIVA>` | `nombre.apellido@tu-empresa.com` |
| `<OWNER_ID_EJECUTIVA>` | `12345678` (id de owner en HubSpot) |
| `<PORTAL_ID>` | `12345678` (id del portal HubSpot) |
| `<PIPELINE_NOMBRE>` | `NOMBRE DEL PIPELINE` |
| `<PIPELINE_ID>` | `12345678` |
| `<STAGE_ID_PRIMERA_REUNION>` | `12345678` |
| `<SDR_1>` | Nombre SDR 1 — `sdr1@tu-empresa.com` — owner `12345678` |
| `<SDR_2>` | Nombre SDR 2 — `sdr2@tu-empresa.com` — owner `12345678` |
| `<ROUTINE_ID>` | `trig_...` (id de la rutina en claude.ai/code/routines) |
| `<SLACK_CUENTA>` | cuenta de Slack conectada al conector de Claude |
| `<SLACK_USER_ID>` | `U0XXXXXXXXX` (DM a uno mismo) |

Al pegar `routine/prompt.md` en la rutina, reemplazar cada marcador por su valor real.
